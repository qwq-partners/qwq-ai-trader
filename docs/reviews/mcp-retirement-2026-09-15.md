# MCP 런타임 정리 — 2026-09-15

## 범위와 판단

사용자가 MCP 부재 경고의 설치/제거 판단을 요청했고, 감사 후 제안한 제거·검증·커밋/푸시·배포/재시작 범위를 승인했다. 기준 checkout은 `76f7120`(운영 소스 `82b5039` + 문서). 주문·전략 설정·킬스위치는 변경하지 않는다.

SDK와 `pykrx-mcp` 실행 파일이 없고, 서버 호출의 인자/응답·거래대금 대 주수 단위도 정합하지 않았다. 설치만 하면 StockValidator의 미검증 수급·검색 버즈 가산이 활성화될 수 있다. 전략 업종 조회 2개의 결과는 전문가 프롬프트가 소비하지 않았으며, 운영 수급 탐지에는 이미 KIS 공급자가 주입된다. 따라서 의존성을 추가하지 않고 불필요한 MCP 런타임을 제거한다.

## 변경과 보존 경계

| 경로 | 처리 |
| --- | --- |
| 봇 부팅·MCP 클라이언트 | 연결 생성·SDK import·외부 서버 실행 코드 제거 |
| 종목 검증 | MCP 조회/파싱/캐시/보조 가산 제거. 공개 결과의 미획득·무가산 및 기존 뉴스/DART 판단 보존 |
| 전략 수급 탐지 | KIS 투자자 일별 경로와 기존 일일 폴백 보존, MCP 폴백 제거 |
| 전략 업종 조회 | 미소비 MCP 요청 제거, 결과 키 호환 유지 |
| 일반 pykrx·네이버 뉴스·DART | 유지, 신규 API/자격증명/패키지 없음 |
| 과거 로그 필터 | 대시보드·자가수정기의 분류 규칙은 유지(런타임 연결이 아님) |

`approved=True`는 기존 fail-open 거래 계약이지 자료 충분성이나 `risk_clear=True`의 증거가 아니다. 이 정리로 없던 자료를 확보했다고 주장하지 않는다. 위험 사이징/팀 정책 승격·canary 시작·투자 성능 개선 판정도 하지 않는다. 과거 MCP가 실제 연결된 환경의 보조 가산은 제거되므로 전체 환경의 신호 불변은 아니다.

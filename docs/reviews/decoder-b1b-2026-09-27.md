## Plan

순서 있는 ENTRY/ITEM 게시, 중첩 CONT 인계·제거만 다룬다. 완성된 private root는 계속
소유하며 READY·정리·실제 해제·제품 decoder 성공으로 표시하지 않는다.

Sol/high 요청 두 조사로 남은 전이와 2MiB 출력 실행기 공백을 나눴고, Astra/high 요청
저자가 정확한 중간 상태·fault·독립 literal oracle·17개 실제 변이 계획을 작성했다.
다른 Astra/xhigh 요청 reviewer는 pytest 파일명 충돌 I1을 발견했다. 새 파일만
`test_b1b_structure.py`로 정정하고, 후속 tail-index 정리 의무와 private 생성자 반환
예외를 명확히 한 뒤 **APPROVE_B1B_PLAN_ONLY**로 재승인했다. 실제 수집 성공은 아직
미관측이며 정적 발견을 실행 실패로 꾸미지 않는다.

요청 모델·effort와 실제 metadata는 구분한다. 실제 모델/effective effort는 미노출·
unverified, 같은 공급자 독립 리뷰이지 cross-provider 검증이 아니다. 원문·해시는
`.superpowers/sdd/2026-09-27-decoder-followup/`에 보존한다.

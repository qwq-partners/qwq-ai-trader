# 지수 + 검증된 기울기(Index-plus) 연구 프로그램 — 사전 등록 (2026-09-30)

> 사용자 지시(09-30): "어떻게 하면 KODEX200 을 이길 수 있을지 … 제안해준 순서대로 가보자". 운영 현금은 KODEX200 으로 옮기지 않는다(사용자 반대),
> KR 신규 매수 중지(`KILL_SWITCH_KR`) 유지. 이 문서는 **결과를 보기 전에** 가설·자료·판정 기준을 고정한다. 결과를 본 뒤 기준을 바꾸지 않는다.

## 0. 배경 — 왜 구조를 바꾸나

- 종목 선택 알파 ≈ 0: 7년 백테스트 SEPA 6셀 포지션 단위 KODEX200 초과 |t|<1.7(`long-window-sepa-vs-kodex200-2026-09.md`), 실거래 −1.66%(t=−3.98).
- 노출 부족: 평균 투자 비중 13~27% → 지수가 오르면 구조적으로 진다(7년 KODEX200 +387% vs 봇 −32~+144%).
- 방향: **기본값을 현금이 아니라 지수로**, 봇은 근거가 있을 때만 근거만큼 지수에서 벗어난다. 각 베팅의 기여 = 포지션별 KODEX200 초과수익(이미 운영 중인 원장 지표).

## 1. 가설과 순서

| 순서 | 가설 | 한 줄 정의 |
|---|---|---|
| H1 | 지수 보유 + 하락 방어 오버레이 | 지수 비중을 추세(MA200)·변동성 규칙으로 조절 |
| H2 | 대형주 모멘텀 기울기 | 대형·유동 종목 중 6~12개월 상대강도 상위 비중 확대, 월 1회 |
| H3 | 가치·퀄리티 기울기 | 저PBR·이익 성장(밸류코어 가설), 월 1회 |
| H4 | 수급·실적 이벤트 | 외국인·기관 순매수 지속·실적 서프라이즈 뒤 드리프트 |

각 가설은 착수 전에 이 문서에 세부 정의를 추가한다(아래 H1 처럼). H2 이후는 H1 기준선 위에 기울기를 얹은 결과로 비교한다.

## 2. 공통 판정 기준 (H2~H4 종목 기울기)

통과 = 아래 **전부**:

1. 수수료·세금 차감 후 포지션 단위 KODEX200 초과수익 평균 > 0, **t ≥ 2**.
2. 표본 앞·뒤 절반 **각각** 평균 > 0.
3. 초과수익 상위 3건 제외 평균 > 0.
4. walk-forward 3구간 중 2구간 이상 양수.
5. 파라미터는 사전 정의값 하나로 판정한다. 이웃 값은 강건성 보고용이며 고르지 않는다.

통과한 가설만 소액 실거래 canary(원장으로 재판정)로 넘어간다. 실패는 기각으로 기록하고 재시도하지 않는다(다른 가설로 이동).

## 3. H1 세부 정의 (고정)

- **자료**: Yahoo `^KS11` 일봉 종가(가격지수, 배당 제외 — 벤치·전략 동일 기준), 2000-01-01~2026-09-28. NaN·0 이하 행은 제외. KODEX200(069500)은 2026-07-31 +24.2% 오염 봉이 있어 수익 계산에 쓰지 않는다(지수와 ETF 차이: 보수 약 0.15%/년, 배당은 양쪽 제외).
- **시점**: t 일 종가까지의 자료로 비중 w_t 를 정하고 t+1 일 수익에 적용한다(미래정보 없음).
- **B0 기준선**: w = 1.
- **H1a 추세**: 종가 > MA200 이면 1, 아니면 0.
- **H1b 변동성**: 20일 실현변동성(σ×√252) ≤ 25% 면 1, 초과면 max(0.4, 25/σ) — 운영 `volatility_targeting.py` 상수 그대로.
- **H1c**: H1a × H1b.
- **현금 수익**: 0(보수적). 민감도로 연 2.5% 도 보고.
- **비용**: 비중 변화 |Δw| 1 당 0.05%(ETF 매매 수수료+슬리피지, ETF 는 매도 거래세 면제).
- **구간**: 전체 2001-01~2026-09(MA200 워밍업 뒤), 3등분(2001~2008, 2009~2016, 2017~2026-09), 참고 2019-06~2026-09(SEPA 연구와 같은 창).
- **H1 판정**:
  - "수익률로 이긴다" = 전체 CAGR > B0 **그리고** 3등분 중 2구간 이상 CAGR > B0 (비용·현금 0 기준).
  - "위험 대비로 이긴다" = 전체 Sharpe > B0 **그리고** MDD 개선 (CAGR 은 질 수 있다).
  - 둘 다 보고한다. 목표(KODEX200 을 이긴다)에 해당하는 것은 전자다.
- **강건성(보고만)**: MA150·MA250, 변동성 임계 20·30%.

## 3-2. H2 세부 정의 (고정 — H1 결과를 본 뒤, H2 결과를 보기 전에 등록)

- **질문**: 지수처럼 100% 투자를 유지하면서, 대형·유동 종목 중 상대강도 상위만 담으면 KOSPI200 을 이기는가.
- **유니버스(시점 정합)**: 매월 말, 그 시점까지 250거래일 이상 이력이 있는 KOSPI 종목 중 **직전 60거래일 평균 거래대금(종가×거래량) 상위 100**.
  후보 목록은 가능하면 **그 시점 상장 목록**(pykrx 날짜별 종목 목록 — 상장폐지 종목 포함)을 쓰고, 불가하면 현재 상장 종목으로 대체하고 생존 편향을 명시.
  우선주·ETF·ETN·스팩·리츠 제외.
- **신호**: 12-1 모멘텀 = 종가(t−21) / 종가(t−252) − 1. 상위 **20종목 동일 비중**.
- **체결**: 월말 종가(t) 신호 → 다음 거래일 **시가** 체결, 한 달 보유 → 다음 리밸런싱. 거래정지·결측 종목은 그달 제외.
- **비용**: 매수 0.014%+슬리피지 0.10%, 매도 0.25%(수수료+거래세 보수 근사)+슬리피지 0.10%. 교체분에만 부과.
- **벤치마크**: Yahoo `^KS200`(KOSPI200 가격지수, KODEX200 추종 대상). 069500 은 교차 확인용. 종목·벤치 모두 배당 제외 가격 수익.
- **구간**: 2010-01~2026-09(자료 가용 시작이 늦으면 기록), 3등분 + 2019-06~ 참고.
- **판정(§2 적용)**:
  - 포지션 = (종목, 보유 월). 포지션 초과 = 종목 월수익(비용 차감) − 같은 기간 ^KS200 수익. 평균 t ≥ 2, 앞·뒤 절반 각각 > 0, 상위 3건 제외 > 0, 3등분 중 2 이상 > 0.
  - 계좌: 포트폴리오 CAGR > ^KS200 CAGR 과 월 초과수익 정보비율(IR)을 함께 보고.
- **강건성(보고만)**: 상위 10·30종목, 6-1 모멘텀, 유니버스 50·200.

## 3-3. H3 세부 정의 (고정 — H2 결과를 본 뒤, H3 결과를 보기 전에 등록)

- **질문**: 시총 비중을 기본으로 두고 가치·퀄리티 점수 상위 절반만 담으면, 같은 유니버스의 시총가중 포트폴리오와 KOSPI200 을 이기는가.
  (H2 진단: 동일 비중 자체가 시총가중 지수 대비 −0.85%/월 → 크기 효과를 분리해야 한다.)
- **현재 엔진과의 관계**: 엔진 인프라(주문·위험·청산·원장)는 그대로 두고 **진입 신호원을 바꾸는 전략 라인 후보**. 통과하면 엔진의 전략 라인으로 구현·canary.
- **유니버스(시점 근사)**: 매월 말 t, FDR 현재 KOSPI 상장 목록(우선주·리츠·ETF·ETN·스팩 제외, H2 와 같은 규칙) 중 t 까지 250거래일 이력이 있는 종목을
  **근사 시총 = 수정종가(t) × 현재 상장주식수** 로 정렬해 상위 200. (과거 시점 상장주식수·시총은 KRX 로그인 없이 불가 → 근사, 생존·사후 편향 명시.)
- **재무(시점 정합)**: OpenDART 사업보고서(연간, `reprt_code 11011`) FY2014~FY2025, 연결(CFS) 우선·없으면 개별(OFS): 자본총계·당기순이익.
  t 시점에 쓰는 재무 = **접수일(`rcept_no` 앞 8자리) ≤ t 인 가장 최근 사업보고서**. 분기·반기 보고서는 쓰지 않는다(단순화, 갱신은 연 1회 3월 말).
  자본총계 ≤ 0 은 제외. 수집 호출은 다중회사 API(`fnlttMultiAcnt`, 회사 100개/호출)로 상한 8,000건 안에서, 키가 필요한 단계는 coordinator 가 실행.
- **신호(t 까지 자료만)**: BM = 자본총계 / 근사시총(t), ROE = 당기순이익 / 자본총계. 유니버스 안 순위 백분위의 평균 = 종합 점수.
- **포트폴리오**
  - **B(기준선)** = 상위 200 시총가중.
  - **H3** = 종합 점수 상위 절반(100) 을 **시총가중**. 월 1회, 다음 거래일 시가 체결(H2 와 같은 체결·비용: 매수 0.014%+0.10%, 매도 0.25%+0.10%, 교체분·비중 변화분).
- **벤치마크**: FDR `KS200`(H2 와 동일), 보조 069500.
- **구간**: 2015-08~2026-08(H2 가격 캐시 `~/.cache/ai_trader/backtest/h2_ohlcv/` 재사용, Naver 수정주가), 3등분 + 앞·뒤 절반.
- **판정**
  - 1차(§2 준용, 포지션 = (종목, 보유 월), 동일 가중 평균): H3 포지션의 KOSPI200 초과 평균 > 0, t ≥ 2, 앞·뒤 절반 > 0, 상위 3건 제외 > 0, 3등분 중 2 이상 > 0.
  - 2차(포트폴리오): H3 CAGR > B CAGR **그리고** > KS200 CAGR, 월 초과수익 IR 보고. B 대비 초과가 양수인데 KS200 에 지면 "유니버스 구성 문제"로 따로 기록.
- **강건성(보고만)**: 상위 1/4(50종목), BM 단독, ROE 단독, 동일 비중 H3(크기 효과 크기 확인용).

# H3 — 가치·퀄리티 기울기 결과 (2026-09-30)

> 사전 등록: `index-plus-program-2026-09.md` §2(공통 판정)·§3-3(H3 정의). 정의·기준은 바꾸지 않았다.
> 정의대로 못 한 부분은 §2 "불가 → 대체 → 영향"에 적었다. 연구 전용 — `src/`·운영·설정·주문 무변경, KIS·DART 무접촉(DART 자료는 이미 수집된 `results/index_plus_h3/dart_fundamentals.csv` 만 사용).

## 결론

**1차(§2 포지션 기준) 기각 → 사전 등록 규칙상 H3 기각(canary 대상 아님).** 2차(포트폴리오 CAGR)는 통과했지만 유의하지 않고, 우위가 마지막 29개월에 몰려 있다.

- **1차**: 포지션(종목, 보유 월) 동일 가중 KOSPI200 초과 평균 **−0.67%/월(t = −6.45)**, 앞·뒤 절반 −0.52%/−0.82%, 상위 3건 제외 −0.70%, 3등분 양수 0/3 — 4기준 모두 기각.
- **2차**: H3 CAGR **+18.23%** > B +13.35% **그리고** > KOSPI200 +15.13% → 사전 등록 문장 그대로 **통과**. 단 월 초과 IR 0.30(t = 0.97, KOSPI200 대비), H3 − B 월 +0.35%(IR 0.53, t = 1.70) — 유의 수준 아님.
- **2차 우위의 출처(사후 진단, 판정에 쓰지 않음)**: H3 − B 는 신호 월말 2024-03-29 **앞 96개월 −0.01%/월(t = −0.04)**, 뒤 29개월 +1.52%/월(t = 2.15).
  뒤 구간은 DART 자료가 FY2023 부터만 있는 금융업 중심 76종목이 유니버스에 처음 들어온 시점이며(그 뒤 H3 비중의 27.6%), 밸류업 국면과 겹친다.
  **8년간 가치·퀄리티 기울기는 같은 유니버스 시총가중을 이기지 못했고, 최근 2.4년의 한 국면이 전체 CAGR 차이를 만들었다.**
- 1차와 2차가 갈린 이유: 포지션 동일 가중 평균은 유니버스 안 중소형 종목의 부진(크기 효과)을 그대로 담는다 — 기준선 B 의 포지션 평균도 −0.79%(t = −8.64), 동일 비중 H3 계좌 CAGR 은 +7.83%.
  H2 진단(거래대금 상위 100 동일 비중 −0.85%/월)과 같은 현상이다. 사전 등록이 1차를 포지션 동일 가중으로 정했으므로 판정은 그대로 둔다.
- 강건성 4종(상위 50·BM 단독·ROE 단독·동일 비중)도 1차 전부 기각. 계좌 CAGR 은 상위 50(+17.21%)·ROE 단독(+16.99%)이 KOSPI200 을 넘고 BM 단독(+12.49%)·동일 비중(+7.83%)은 못 넘는다.
- 사전 등록 규칙대로 H3 는 재시도하지 않는다.

## 1. 방법 (§3-3 그대로, 구현 규칙 명시)

- **달력**: FDR `KS200`(KOSPI200 가격지수) 거래일 — H2 와 동일. 월말 t = 그 달 마지막 거래일, 체결일 = 다음 거래일.
- **후보**: `universe_candidates.csv` 808종목 = FDR 현재 KOSPI 상장 942 에서 H2 제외 규칙(우선주·리츠·ETF·ETN·스팩) 적용분. 가격은 H2 캐시 Naver 수정주가(누락 0).
- **유니버스(t 까지 자료만)**: t 까지 유효 종가 250행 이상인 종목을 근사 시총 = 수정종가(t, 결측이면 t 까지 마지막 종가) × 현재 상장주식수(`stocks`) 로 정렬해 상위 200. 동률은 종목코드 순.
- **재무(시점 정합)**: (사업연도, 회사)마다 연결(CFS) 행에 자본총계·당기순이익이 **둘 다** 있으면 CFS, 아니면 OFS 행 전체(계정 혼용 없음).
  t 에 쓰는 재무 = **접수일(`rcept_date`) ≤ t 인 행 중 사업연도가 가장 최근인 것**. 접수일이 사업연도+2 이상인 정정 공시 행도 그 접수일을 시점으로 쓴다(보수적 — 원 공시일은 자료에 없음).
  접수일 = t 인 공시는 t 에 쓴다(신호는 t 장 마감 뒤, 체결은 t+1 시가).
- **점수 가능 유니버스**: 상위 200 중 재무가 있고 자본총계 > 0, 순이익 있음. 나머지는 B·H3 모두에서 제외.
- **신호**: BM = 자본총계/근사시총(t), ROE = 순이익/자본총계. 점수 가능 유니버스 안 순위 백분위(높을수록 좋음)의 평균. 동률은 종목코드 순.
- **포트폴리오**: **B** = 점수 가능 유니버스 전체 시총가중(월평균 171.9종목). **H3** = 점수 상위 100 시총가중(사전 등록의 "(100)" 을 고정 수로 적용 — 점수 가능 종목이 200 보다 적으므로 실제로는 상위 약 58%).
  비중은 t 근사 시총 비례. 강건성: 상위 50, BM 단독, ROE 단독, 동일 비중.
- **체결**: 체결일 시가. 새 편입 종목이 그날 시가가 없으면(정지·결측) 그달 제외하고 나머지 비중을 재정규화. 이미 보유하던 종목은 계속 보유.
  청산일 시가가 없으면 t 까지 마지막 종가(H3 본 결과 52건).
- **비용(교체분·비중 변화분)** — 구현 규칙:
  - 보유 월 k 끝의 **드리프트 비중** = w_k·(1+g) / Σ w_k·(1+g) (g = 체결가 k → k+1 수익).
  - 매수분 f_buy = max(w_k − 직전 달 드리프트 비중, 0)/w_k (새 편입 = 1), 매도분 f_sell = max(드리프트 비중 − w_{k+1}, 0)/드리프트 비중 (편출 = 1, 마지막 달은 전량 청산 = 1).
  - 포지션 순수익 = (1+g)(1 − 0.35%·f_sell)/(1 + 0.114%·f_buy) − 1 (매수 0.014%+0.10%, 매도 0.25%+0.10% — H2 와 동일).
  - 따라서 시총가중에서 가격만 움직여 생기는 비중 변화는 거래가 없어 비용 0, 목표 비중과 드리프트 비중의 차이(재조정)에만 비용이 붙는다. 동일 비중 변형은 매달 동일 비중 복귀 매매에 비용이 붙는다.
  - 계좌 월수익 = Σ w_k·순수익 (비용을 비중 단위로 붙인 1차 근사).
- **포지션** = (종목, 보유 월). 초과 = 순수익 − 같은 두 체결일 **시가** 기준 KOSPI200 수익. `positions.csv` 의 `month` 는 신호 월말.
- **판정**: 1차 = §2 4기준(포지션 동일 가중: 평균 > 0 그리고 t ≥ 2, 앞·뒤 절반 각각 > 0, 상위 3건 제외 > 0, 3등분 중 2 이상 > 0). 2차 = H3 CAGR > B CAGR **그리고** > KS200 CAGR, 월 초과 IR 보고.
  판정·지표 코드는 H2 의 `evaluate`·`pos_metrics`·`acc_metrics` 를 그대로 쓰고 계좌 합산만 비중 가중으로 바꿨다.

## 4. 해석

- **질문(§3-3)**: 시총 비중을 기본으로 두고 가치·퀄리티 상위 절반만 담으면 같은 유니버스 시총가중과 KOSPI200 을 이기는가
  → 11년 합계 CAGR 로는 **예**(+18.2% vs +13.4% vs +15.1%), 그러나 **사전 등록 1차 기준(포지션 단위)으로는 아니다**, 그리고 계좌 우위도 통계적으로 약하고 한 국면에 몰려 있다.
- 포지션 평균이 크게 음수인 것은 선택의 실패라기보다 **크기 효과**다 — 같은 유니버스 B 의 포지션 평균(−0.79%)과 H3(−0.67%) 차이는 +0.12%p/월뿐이고, 동일 비중으로 담으면 계좌도 +7.8% 로 지수에 크게 진다. 이 기간 KOSPI200 수익은 소수 초대형주에 집중됐다.
- 가치·퀄리티 기울기의 순수 효과(H3 − B)는 2024-03 전 96개월 동안 0(−0.01%/월)이다. 2024-03 뒤 +1.5%/월은 (1) 그때 처음 유니버스에 들어온 금융주(저 PBR·고 ROE → H3 가 담음, 뒤 구간 비중 27.6%)와 (2) 밸류업 국면이 겹친 결과로,
  **자료 결측이 풀린 시점과 우위 시점이 같아 이 우위를 전략의 지속 효과로 볼 근거가 부족하다.**
- 성분별로는 ROE(퀄리티) 쪽이 BM(가치)보다 낫다(계좌 IR 0.33 vs −0.29) — 보고만, 고르지 않는다(§2-5).
- 운영 함의: 현재 엔진의 진입 신호원을 이 점수로 바꾸는 전략 라인 후보는 **통과하지 못했다**. canary 로 넘기지 않는다.

## DO — 비용 항목과 상한 계산

`src/analytics/model_comparison_budget.py`(순수 함수)가 공표 요율(`llm_pricing` 단가표, 청구 보증 아님)을 Decimal 로 직접 계산해(1e-9 단위 올림) 역할별 호출 비용 → 판단 비용 → 비교 1쌍(현행+후보) 비용 → 가용액×(1−예비 비율)에서의 비교 수를 낸다. 판단 비용은 두 가지로 분리한다: **expected**(역할별 1회 × 1.1, `retry_on_empty=1`·실측 6회 중 1회 빈 응답의 평균 가정)와 **max**(역할별 최대 2회 + 단일 폴백의 **공급자 체인 전체** — `STRATEGY_ANALYSIS` 기본 `gpt-5.6-sol` 900/100 토큰에 폴백 `gemini-3.1-pro-preview` 900/100 토큰까지 합산 — 경로상 최대 비용. `LLMManager` 는 기본 공급자 실패 시 폴백 공급자를 한 번 더 부르므로 폴백 1회만 세면 상한이 아니다). 상한은 max 기준으로만 말하고 둘을 섞지 않는다. 입력 900 토큰(공통 사실 1,652바이트+역할 지시 추정), 출력 400 토큰(MAX_TOKENS, 추론 토큰 포함) 가정이며 실제 토큰은 판단 기록 `attempts[].input_tokens/output_tokens` 로 치환한다.

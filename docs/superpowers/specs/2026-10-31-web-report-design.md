## 1. 목표와 비목표

**목표.** 장전 07:40 / 장중 13:10 / 장후 16:40 텔레그램 발송 때 같은 내용을 더 읽기 좋은 웹 페이지로 제공하고, 텔레그램 본문 끝에 그 링크를 붙인다. 독자가 "지금 한국 시장을 어떻게 보고, 무엇이 확인되면 생각을 바꾸는가"를 1분 안에 파악하게 한다.

**비목표.**
- 새 자료 조회·새 LLM 호출·새 전망 수치 생성. 웹은 **저장된 발송 자료의 다른 표현**이다.

- 실시간 시세 위젯. (KIS 자료 공개 재배포 문제·연결 부담.)

## 3. 정보 구조(IA) — 하루 한 페이지, 슬롯은 탭

URL: `https://qwq.ai.kr/reports/2026-10-30#after` (아카이브 `https://qwq.ai.kr/reports/`)

하루 한 페이지인 이유: 애널리스트 리포트의 가치는 **"장전에 이렇게 봤고 → 장중에 이렇게 확인됐고 → 장후에 이렇게 정리된다"**는 흐름이다. 슬롯별 파일 3개보다 같은 날 안에서 판단 변화를 추적할 수 있어야 한다. 텔레그램 링크는 해당 슬롯 앵커로 연다.

```
┌ 상단 고정 ────────────────────────────────────────┐
│ QWQ 시장 리포트  ·  2026-10-30 (목)  ‹ 전일  익일 › │
│ [장전 07:40] [장중 13:10] [장후 16:40 ●]            │  ← 미발송 슬롯은 회색 "보류/휴장"
└───────────────────────────────────────────────────┘
1  한 줄 판단 (thesis)              ← 가장 크게. 근거 배지 E1 E2 F1
2  핵심 이슈 1~2  (카드)            ← 사건 → 영향 경로 → 반대 근거 → 관찰 조건, 4단계 세로 흐름
3  시장 지표                        ← KOSPI/KOSDAQ/미국 카드, 기준 시각·확정 여부 라벨
4  업종 흐름                        ← 섹터 ETF 10개 가로 막대(상승 빨강·하락 파랑, 한국 관례)
5  확인 조건 / 반증 조건 표          ← "이게 보이면 유지 · 이게 보이면 수정" 두 열
6  근거 · 출처                      ← E번호별 제목·제공처·발행/수집 시각·한계·원문 링크
7  자료 범위와 한계 · 고지           ← 커버리지 배지(확보/일부/미확보), 투자 권유 아님
```

### 3.1 각 영역의 내용 규칙

1. **한 줄 판단.** `thesis.text` 그대로. 사실형 슬롯이면 "시장 방향 판단자료 미확보" 문장을 같은 자리에 중립 톤으로. 수치·방향 아이콘을 덧붙이지 않는다(판단은 글이다).
2. **핵심 이슈 카드.** 4단계는 라벨을 고정(사건/영향/반대/관찰)해 독자가 매일 같은 자리에서 같은 종류의 정보를 읽게 한다. "반대 근거"는 시각적으로 접지 않고 **항상 펼친다** — 균형 잡힌 리포트의 핵심이고 접으면 아무도 안 읽는다.
3. **시장 지표 카드.** 값보다 **기준 시각과 확정 여부**를 더 눈에 띄게. `finality=unverified`면 "확정 종가 아님" 배지, `historical_minute`면 "15:32 분 관측". 전일 대비가 없으면 빈칸이 아니라 "전일 대비 미확보"를 쓴다. 한국 지수 장전 기준일은 카드 안에 표기.
4. **업종 흐름.** 유일한 차트. 막대 10개, 0선 기준 좌우, 값 라벨 끝에. "확인 10개 중 최근 1세션, 전체 업종 순위 아님" 캡션을 차트 아래 고정. 모두 하락이면 상위를 "강세"로 쓰지 않는다(기존 규칙).
5. **확인/반증 표.** 이슈별 `watch`와 thesis에서 뽑는다. LLM 출력 스키마에는 `invalidate`가 없으므로(#309의 `invalidate`는 #310에서 빠짐) **P1에서는 `watch` 한 열만** 두고, 두 열 표는 스키마에 `invalidate` 필드를 되살리는 별도 변경 뒤에 켠다.
6. **근거·출처.** 본문 배지(E1)를 누르면 이 목록의 해당 행으로 스크롤+하이라이트(CSS `:target`). 발행시각 미검증·제공처 발췌·공시 색인(원문 아님) 같은 한계를 행마다 표기. 외부 링크는 `rel="noopener nofollow"`, 새 탭.
7. **고지.** "자동 생성·투자 권유 아님·자료 한계" 고정 문구 + 생성 시각 + 발송 상태(API 수락 시각).

### 3.2 있으면 좋은 것(우선순위 순, 전부 기존 자료)

| 우선 | 항목 | 자료 | 비고 |
|---|---|---|---|
| P1 | 위 1~7 + 텔레그램 링크 | 전부 저장됨 | 신규 조회 0 |
| P2 | 앞으로 5일 일정·최근 공시·거시 지표 3개 접이식 표 | 근거 봉투의 calendar/disclosure/macro 레코드 | 봉투에 이미 들어 있으나 본문엔 인용된 것만 보임 → 웹에서는 전체 노출 가치 |
| P2 | 하루 흐름 요약: 장전 thesis → 장후 thesis 나란히 | 같은 날 슬롯 2개 | "판단 유지/수정" 표시는 사람이 읽고 판단, 자동 분류 안 함 |
| P3 | 전일 장전 판단 복기 | 기존 장전 전망 사후 평가 원장(20:30) | 적중률 %는 표시 금지(표본·비예측 행 혼재). 문장 대조만 |
| P3 | 지수 최근 20세션 스파크라인 | `kospi_benchmark` 일봉 캐시 | 캐시 신선도 검사 통과분만, 아니면 생략 |
| P4 | 아카이브 월별 목록·검색 | `slots`/`payloads` | 정적 index.html 재생성 |

**넣지 않을 것.** 종목별 수급·외국인 순매수(미확보 자료), 시장 체온계/점수(확률로 읽힘), 실시간 갱신, 댓글.

## 4. UX 원칙

- **모바일 우선.** 텔레그램 인앱 브라우저에서 처음 열린다. 본문 폰트 17px 이상, 한 줄 길이 ≤ 40자, 좌우 여백 16px, 가로 스크롤 금지.
- **색은 한국 관례.** 상승 빨강 `#d64545`, 하락 파랑 `#2f6fd6`, 중립 회색. 색만으로 뜻을 전하지 않고 부호(+/−)와 함께.
- **시각 표기 통일.** `2026/10/30 15:32 KST`. "발행"·"수집"·"관측"·"기준일"을 섞지 않고 라벨로 구분(기존 `_display_time` 재사용).
- **다크/라이트** `prefers-color-scheme` 자동. 저장 없음.
- **JS 없이 완전 동작.** 탭은 `:target`/앵커, 근거 점프도 앵커. JS는 "복사"·"현재 탭 기억" 정도만 선택적으로.
- **하나의 파일.** CSS 인라인, 외부 스크립트 0, 폰트는 시스템 스택(Pretendard가 있으면 사용). 100KB 이하, 추적기 없음.
- **인쇄/PDF.** `@media print`에서 탭 전부 펼침, 링크 URL 각주.
- **접근성.** 제목 계층 h1→h2, 막대는 `<table>` 대체 텍스트, 배지는 `aria-label`, 대비 4.5:1.
- **불변.** 발송된 슬롯의 페이지 내용은 다시 쓰지 않는다(기존 슬롯 소비 계약과 동일). 재생성은 같은 DB 행에서만, 결과는 동일해야 한다.

## 5. 전달 흐름(구현 시)

```
prepare_market_report → final_body ─┐
                                     ├─ publish_report(text + "\n📄 전문·근거 보기: https://qwq.ai.kr/reports/2026-10-30#after")
render_day_html(day, slots) → 파일 ─┘
```

1. 발송 직전 `~/.cache/ai_trader/report_delivery/html/2026-10-30.html`을 쓴다(임시 파일 → `os.replace`). 파일 쓰기 실패는 **발송을 막지 않고** 링크 줄만 생략한다.
2. 텔레그램 본문 마지막 줄에 링크 1줄 추가. 3000자/60줄 한도 안에 들어가야 하며 넘으면 링크를 생략한다(본문 우선).
3. 링크 미리보기는 현재 전체 OFF다. 우리 도메인만 미리보기를 켤지(`link_preview_options.url`)는 OG 태그를 넣은 뒤 1회 시험하고 결정.
4. 대시보드 aiohttp에 `add_static("/reports", html_dir)` 1줄 + `/reports/` → `index.html`. 디렉터리 목록은 끈다.
5. 아카이브 `index.html`은 매 발송 때 `slots`에서 재생성.

## 6. 리스크·열린 결정

1. **공개 범위.** qwq.ai.kr은 지금 인증 없이 대시보드 전체(`/api/portfolio` 포함)가 열려 있다. 리포트 자체는 공개 자료만 담지만, 리포트 링크를 채널로 뿌리면 도메인 방문이 늘어 **대시보드 노출이 함께 커진다.** 권고: Cloudflare Access로 `/reports/*`만 공개, 나머지는 로그인. 이 작업과 별도 운영 변경이다.
2. **자료 재배포.** KIS 지수 참고값·KRX ETF 등락을 공개 웹에 올리는 것은 텔레그램 채널 발송과 같은 성격이지만, 영구 URL은 검색에 노출된다. `robots.txt` noindex를 기본으로 하고, 공개 색인은 별도 결정.
3. **봇 프로세스 의존.** 8080은 봇 안에 있으므로 봇이 내려가면 링크가 죽는다. 정적 파일이므로 나중에 Cloudflare Pages/R2로 옮기기 쉽다(P4).
4. **LLM 본문 0건.** 웹의 가치는 조사형 본문에서 나온다. 자연 발송 1건 수락 전에는 사실형 렌더로 먼저 확인한다.
5. **반증 조건 필드.** 두 열 표를 원하면 `issues[].invalidate`를 스키마에 추가하는 LLM 계약 변경이 필요하다(별도 PR, 검증기 포함).

# 한 종목 장 상태 기술 파일럿

목적: 좋은 종목과 진입 시점의 비용 후 성과를 검증하기 전에, 실제 호가·체결 상태의 결합과 수집 품질을 짧은 구간에서 확인한다. 사용자가 후속 구현/검증/배포를 승인했다. 기존 월USD100 원장·매수 중지·운영 시세 수요·보유관리는 보존한다.

## 선택한 구조

기존 봇 시작 경로에 명시 `runner-market-state-pilot-v1`을 추가한다. 한 종목, 동일 평일 KRX 09:00 이상~15:20 미만의 미래 구간, 최대300초다. 휴장 여부는 이 시간 형식 검사로 증명하지 않는다. 기존 단일 피드/소켓과 유한 원장·종료 태스크를 사용한다. 스크리너/신호/주문 준비 이벤트로 모집단을 만들지 않는다. 경제성 연구 계약/수수료/자본을 꾸며 넣지 않고 별도 기술 연구 문서로 검증한다.

대안인 임의 order_ready 주입은 연구 모집단을 오염시키므로 사용하지 않는다. 두 번째 KIS 연결은 동일 키 연결을 방해하므로 만들지 않는다.

- 계약은 한 symbol과 시작/종료, 소스/설정/용량 근거, 메모리/큐/파일 및 상태 레코드 한도를 고정한다. 시작 전 한 번만 정적 lease를 설치하고 종료 절대시각에 단조시계 만료를 결합한다.
- 운영 PRICE/BOOK 수요를 모두 우선 보존한다. 여유와 불확실 점유를 구분한다. 3채널 묶음의 논리 배정·송신·ACK·수신을 따로 표시한다. 초과/미확인은 관측 불완전이며 운영 시세를 줄여 성공시키지 않는다.
- 버퍼는 해당 종목의 ws_quote/market_state 및 구독 증거만 받는다. 창 이전 가격/상태와 시작 훅의 경제성 이벤트는 제외한다. 원장 봉인은 수집 종료이며 봇 종료가 아니다.
- 준비 완료는 파일 writer만으로 판정하지 않는다. 실제 운영 수요에 대한 전체 정적 묶음/동일 연결 요청 증거가 필요하다. ACK/수신은 별도로 표시한다.
- 실설치는 신규 날짜/고정 SHA·설정·시간·한 종목을 검증한 기존 단발 시작/실패 영수증 경로로만 한다. 구독 여유가 검증되지 않으면 활성화를 예약하지 않고 근거와 후속 조치를 남긴다.
- 원천 침묵은 정상 장 증거가 아니다. 장운영0건도 UNKNOWN이다. 유용한 기술 관측은 유효63필드 호가+47필드 체결이 실제 창에 있고, 누락/지연/봉인을 따로 검토한 경우다. 수집 완전성은 경제성 승인과 다르다.

## 완료 기준

오류 계약/타임존/시간역행/만료/중복설치/채널부족/불확실점유/실패원장 검사를 통과하고 기존 관측 검사를 유지한다. 전체 검사·비밀정보 검사·독립 중요 리뷰 뒤 통합한다. 운영 배포는 장외 정상 상태와 보호 지문/사용액 보존을 확인한다. 실수집 일정 및 달성 여부를 코드 배포와 구분한다.

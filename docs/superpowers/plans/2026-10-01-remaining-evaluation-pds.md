# 남은 엔진 평가 작업 Plan → Do → See

> **For agentic workers:** 연구·검증 작업을 아래 순서로 수행한다. 제품 구현이 필요한 별도 범위는 superpowers:executing-plans 또는 subagent-driven-development를 적용한다.

**Goal:** 종목 선정과 진입 시점이 비용 차감 수익에 주는 효과를 판단할 수 있도록, 지금 확보 가능한 비교자료와 수집 후 평가 경로를 완성한다.

**Architecture:** 승인·예약된 제품 커밋/연구/운영 입력은 고정한다. 기존 계산기로 평가 리허설을 수행하고 공개 반도체 제외 자료는 사전 고정한 정의로 별도 수집·검증한다. 미래 자료와 독립 계좌 원천이 필요한 작업은 정확한 종료 조건을 남긴다.

**Tech Stack:** 기존 Python 분석기, 합성 JSON/JSONL, 삼성자산운용 공개 GET, CSV/JSON 증거.

**Spec:** `docs/operations/capture-execution-2026-10-02.md`, `docs/research/current-engine-selection-entry-protocol-2026-09-30.md`, 기존 연간 자료의 frozen_collection_plan.

## Global Constraints

- 사용자 요청은 남은 작업의 순차 Plan→Do→See 실행이다. 기완료 설치/예약을 반복하지 않는다.
- 제품 대상 `5468208e2bf481eabae5c54da490c7da972756e1`, 실제 study/manifest/once/grant/timer/운영 설정과 매수 중지를 바꾸지 않는다. 주문·재시작·배포·새 실시간 수집 없음.
- 원장은 수집 당시 study 원문 SHA로 검증한다. 0/10/30bp는 원본을 보존한 명시 파생 분석이며 유리한 시나리오만 고르지 않는다.
- 계좌/자격증명/운영 로그를 추가 조회하지 않는다. 독립 체결/입출금 원천이 없으면 계좌 총수익과 청산 정확도는 미확정이다.
- 연간 공개자료의 기간·제외집합·수익 산식·품질 기준 0.02%p는 기존 계획 그대로다. 새 회차의 공개 GET은 직렬·간격2초 이상·최대485회이며429/권한 오류 시 즉시 멈춘다. 현재 비중/가격으로 결측을 채우지 않는다.
- 코디네이터만 통합. 작업자는 소스/공개자료/합성자료만 다루고 모델·effort·실제 metadata 공개 여부를 기록한다.

## Review Focus

- 예약된 실제 입력을 연구 준비로 수정하거나 일회 영수증을 소비하지 않았는가.
- 합성 성공과 실제 수집 성공, 장중 코드와 연속매매 증거를 혼동하지 않았는가.
- 같은 후보/수량·전체 분모·불명/미짝을 보존하며 부분합계를 계좌 수익으로 부르지 않는가.
- 과거 바스켓 날짜·기업행위/리밸런싱·지수 재구성 차이를 검증했는가.
- 같은 원천을 독립 계좌 증거로 세거나 사후에 좋은 기간/제외집합을 고르지 않았는가.

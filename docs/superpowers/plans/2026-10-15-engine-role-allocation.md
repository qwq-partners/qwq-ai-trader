# 거래 엔진 용도별 모델 배분과 10월16일 관측 설치

## PLAN

목적은 종목 선정·진입 시점의 비용 후 성과를 개선하는 것이다. 공개 코딩 순위를 거래 수익 증거로 쓰지 않는다. 사용자는 거래 엔진을 우선하고 월 USD100 한도를 유지하면서 적절한 배분과 앞서 제안한 배포·관측 설치를 승인했다. 개발 에이전트의 전역 배분 규칙은 이 작업 범위가 아니다.

1. 실제 호출 경로, 공식 가격·추론 설정, 예산·계정 접근 가능성을 대조한다. 공급자 키의 존재만 확인하며 값은 기록하지 않는다.
2. 기존 경로를 유지하는 용도별 진입점을 추가한다. 한 줄 설명과 아침 보고는 정식 Gemini 3.1 Flash-Lite/minimal, 후속 복기는 GPT-6.1 Sol/medium을 사용한다. 출력·입력·시간 상한, 한 번의 시도, 동일 월 예산 원장을 적용한다. 후속 복기는 위키를 거쳐 재조정에 참고될 수 있으므로 격리된 실험이라고 부르지 않는다.
3. 신모델 지원 가능성과 같은 입력의 제한된 비교를 확인한다. Gemini 4 Argon은 후보로 검증하며 품질 우위를 미리 가정하지 않는다. Claude는 엔진 API 연결·키가 없어 이번 배분에서 활성화하지 않는다.
4. 추론 출력과 자동 캐시 쓰기, 할인 종료 후 가격까지 보수적으로 계산한다. 과거 정산 기록은 재계산하거나 초기화하지 않는다.
5. 관련 시험·전체 verify·독립 최종 리뷰·CI 후 커밋/푸시/병합한다. 최종 고정 SHA를 장외 배포하고 건강 상태를 확인한 뒤 같은 소스·설정으로 10월16일 설치물을 만든다.
6. 검증된 날짜별 설치기로만 관측을 예약한다. 기존 원장·소비 증거를 보존하고 정확한 다음 실행 시각을 확인한다. 설치 완료는 관측 성공이나 수익성 증명이 아니다.

## 소유권과 검증

- 코디네이터: 통합, 공식 자료·API 자격 검증, 문서, 운영 배포·실제 설치물. 운영 자료는 비공개 경로에만 보관한다.
- 독립 Astra/high 구현자: 역할 진입점·해당 호출부·시험. 다른 worker는 가격표·관련 시험만 수정하며 동일 기준 SHA의 별도 worktree를 쓴다.
- 독립 최종 리뷰어: Astra/xhigh, 작성자의 중요 변경을 스스로 승인하지 않는다. 실제 모델 metadata가 없으면 요청 모델과 구분해 미확인으로 기록한다.
- 필수 검증: 정확한 역할별 payload, 거절·빈 응답·취소 후 추가 유료 시도 없음, 월 80/95/100 정책, 기존 진입/Bull·Bear/매수 중지 불변, 가격 상한·문맥 경계·할인 종료, 시험 중 외부 네트워크·운영 상태 접근0.

## DO / SEE

실행 증거와 최종 운영 상태는 후속 운영 문서에 기록한다. 이 계획 작성 시점에는 새 코드 배포·10월16일 관측 설치·신규 유료 비교를 수행하지 않았다.

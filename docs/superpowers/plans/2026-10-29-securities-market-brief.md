# R02 증권 리포트형 시장 브리프 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. 각 단계는 Plan → Do → See로 기록한다.

**Goal:** 채널 장전·장중·장후 본문을 한국 증시 리서치 브리프처럼 핵심 판단·근거·국내 관전 포인트 순서로 읽을 수 있게 바꾼다.
**Architecture:** 기존 검증된 MarketSnapshot의 숫자/날짜만 결정론적으로 요약한다. 수집·발송 스케줄·거래 판단은 그대로이며 유료 LLM·새 API·시험 발송을 추가하지 않는다.
**Tech Stack:** Python·기존 Telegram HTML renderer·pytest.
**Spec:** [보고 계약](../../agents/reporting.md), [R02 작업 원장](../../operations/execution-roadmap.md#r02-mobile-feedback-20261029), 사용자10/29 지시 “증권레포트형태로.. 한국주식전문가가 보내준것처럼”.

## 설계와 제약

- 기존 기능/안전 계약을 유지한 본문 개선이다. 짧은 텍스트 리포트를 채택한다. 이미지 중심이나 새 LLM 요약은 발송량·비용·원천 정합성 부담을 늘리므로 이번 범위에서 채택하지 않는다.
- 구조: 한국증시 모닝브리프/장중 시황/마감 점검 → 시장 판단 → 표시 자료의 날짜·지표·상대 차이 → 국내 관전 포인트 → 짧은 자료 범위/실제 표시 출처. 전문가 자격이나 특정 증권사 작성인 것처럼 꾸미지 않는다.
- 검증된 지수의 상승/하락/혼조·보합을 표본 범위 안에서 요약한다. 미국만 있으면 미국 관측이라는 점을 밝힌다. SOX/나스닥이 모두 있을 때 상대 차이를 %p로 설명할 수 있으나 국내 강세·원인을 만들지 않는다. 단일 지수는 그 지수만 이름으로 요약한다.
- 국내 ETF는 해당 기준일·최근1세션·관측집단 안의 상하위이며 업종 전체 순위/시장 폭이 아니다. 모두 하락한 경우 상대 상위를 강세로 표현하지 않는다.
- 원천 미확인 장중 KIS 응답은 참고자료, 장후 분 관측은 미확정 가격을 유지한다. 이 값만으로 전일 대비/국내 방향/종가 확정을 만들지 않는다. 기존 None 반환·날짜/시간/결측 검증 함수를 완화하지 않는다.
- 국내 확인 문구는 장전의 개장 후 조건, 장중의 추가 확인, 장후의 다음 거래일 조건으로 구분한다. 실제 수급·뉴스·종목 가격이 없는 상태에서 원인/확률/목표가/매수 권고를 생성하지 않는다.
- 출처는 실제 표시한 자료군만 연결한다. 미국만이면 Yahoo Finance이며 국내 KIS/ETF를 나열하지 않는다. HTML escape·1,800자/35줄 이내·계좌/엔진정보 비노출을 유지한다. 반복적인 안내는 자료 범위 한 곳으로 모은다.
- 운영40714a19/PID3817842·21시 개인 보고·T04 남은 슬롯·기존 정리 기한은 coordinator만 다룬다. 구현자에게 운영/자격/개인 원자료를 주지 않는다. 이미 완료된17시 단발 실행기는 재사용/재시도하지 않는다.

## Review Focus

1. 미국만/1개/혼조/모두하락/보합과 반도체 상대강도에서 과도한 국내 방향 주장이 생기지 않는가.
2. 국내 수치의 시점과 실제 기준일, 장중 참고/장후 미확정 가격이라는 구분이 제목·요약에서도 유지되는가.
3. ETF 상대 상위가 절대 상승이나 전체 업종 순위로 바뀌지 않는가.
4. 출처·결측이 실제 표시 자료와 맞고 과거/미래·비유한 자료를 살려내지 않는가.
5. 긴/HTML 특수 이름과 혼합 자료에서 한 메시지 상한·비공개 문맥 차단을 유지하는가.

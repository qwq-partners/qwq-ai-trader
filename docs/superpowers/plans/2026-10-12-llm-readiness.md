# LLM·관측 준비 실행 계획

기준 SHA: `5925490771b4cc53d7ee0aa82e48268d16b17504`. 설계: [일별 검증 설계](../specs/2026-10-12-live-learning-readiness-design.md).

## Plan

사용자 요청에 따라 순서를 정하고 바로 진행한다. 이번 변경은 공유 LLM 경로와 전략 제안에 영향을 주므로 critical로 분류한다. 운영 주문·설정·킬스위치·수집 예약은 변경하지 않는다. 로컬 검증은 외부 API와 운영 자격증명을 쓰지 않는다.

| 담당 | 요청 모델/effort | 파일·작업 | 한도 |
|---|---|---|---|
| 조정자 | 현재 세션, 실제 모델 메타데이터 미노출 | llm_strategist.py, researchers.py 호출 호환성, 전용 테스트/기존 T11검사, 문서, 통합 | 한 번의 한정된 결함 정비 |
| transport worker | gpt-6-astra/high | utils/llm.py, llm_pricing.py, test_llm_transport_contract.py | 25분, 추가 위임 없음 |
| 독립 최종 리뷰 | claude-opus-5/xhigh 요청 | 비밀정보 없는 소스·diff·테스트 근거, 도구 비활성 | 전체 재리뷰 최대12분/$8, 최종 delta 최대5분/$3 |

구현자는 자기 critical 변경을 최종 승인하지 않는다. 실제 모델 식별은 반환 메타데이터가 있을 때만 확정한다. 별도 작업트리/파일 소유권을 유지하고 조정자만 통합한다.

독립1차 리뷰의 실제 모델은 `claude-opus-5`(assistant/result 메타데이터 일치), 요청 xhigh이며 유효 강도는 별도 단정하지 않는다. 후속 전송/취소/리뷰 보완은 동일 Astra/high 작업자에게 각각10분/15분으로 한정 위임했다. 최종 소스 변경은 재리뷰 후 통합한다.

전체 재리뷰와 최종 delta 재리뷰 모두 실제 `claude-opus-5` 확인·APPROVE, 도구 위반/타임아웃0. transport 작업자의 실제 모델 메타데이터는 미노출로 미확인이다. P1 소스 보존 사전 감사는 기존 Sol/high 읽기 전용 작업자에게8분/1200단어로 위임했고 파일/운영 변경 없이 끝났다.

## Do

1. 공식 단가·추론 제어와 기존 호출 경로를 대조하고 예상 호출량별 비용을 산술 계산한다.
2. 호출 결함을 재현하는 테스트를 RED로 실행한다. 옵션/비용/예산/메타데이터를 수정하고 GREEN으로 확인한다.
3. 잘못된 계좌 수익 산식과 실패 시 손절 변경을 재현한다. 목표와 fallback을 바꾸되 응답 스키마는 유지한다.
4. 공통 입력 자료·장 상태·응답 이후 가격 연결과 일별 운영 판단의 다음 단계를 문서화한다.

## See

관련 테스트 UTC/KST, 전체 verify(비밀정보 검사 포함), 독립 소스 리뷰. 발견된 결함은 회귀 시험 후 재리뷰한다. 최종 결과·남은 한계·운영 미적용 여부를 CLAUDE/CHANGELOG/docs index/모니터링 정본에 기록한다. 검증된 코드만 커밋·push·PR로 통합하고 PR을 작업에 연결한다. 별도 실제 수집/모델 비교/수익 판정은 구현 검증과 구분한다.

최종 결과: UTC/KST 관련205검사 각각 통과, 전체4999 passed/2 skipped/2 known xfailed·격리 위반0·문법/비밀정보 검사 통과. 독립 종결 승인 뒤 통합하며 새 관측/모델 비교/운영 배포는 미실행이다.

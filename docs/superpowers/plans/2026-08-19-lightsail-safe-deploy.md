# Lightsail 안전 배포 구현 계획

1. 배포 계약을 테스트로 고정한다.
   - 로컬 실행기의 기본 모드는 읽기 전용 점검이어야 한다.
   - `--deploy`는 정확한 `origin/main` SHA를 원격 실행기에 전달해야 한다.
   - 원격 실행기는 정상 배포와 상태 확인 실패 시 롤백을 각각 검증해야 한다.
2. `scripts/deploy/deploy_lightsail.sh`를 구현한다.
   - 로컬 저장소/브랜치/동기화 상태 및 SSH 연결을 검사한다.
   - 기본 점검과 명시적 실제 배포 모드를 제공한다.
3. `scripts/deploy/remote_deploy.sh`를 구현한다.
   - 잠금, 깨끗한 작업 트리, 대상 SHA 검증, 검증, 재시작, 상태 확인, 롤백을 담당한다.
   - 테스트 가능한 환경 변수 재정의를 제공하되 운영 기본값은 고정한다.
4. 운영 문서와 문서 색인을 갱신한다.
5. 전체 검증 후 PR을 만들고 CI 통과를 확인한 뒤 병합한다.
6. 병합된 `main`으로 읽기 전용 점검 후 첫 실제 배포를 수행하고 상태를 확인한다.

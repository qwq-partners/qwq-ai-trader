> 상태: **승인 — 구현 진행 중** · 작성 2026-08-04 · LLM 정성 검증 단계 추가 2026-08-04
> 배경: 현행 스크리닝은 전 라인이 모멘텀 우선이라 가치/성장 후보 도출이 구조적으로 불가
> (코어홀딩 진입 필터 "60일 ≥+5% + 신고가 80% 이내"가 저평가 소외주를 원천 배제,
> 성장률 데이터는 수집 자체가 없음). 사용자 결정: 가치·성장 30~40% 배분, **장기 보유**.

## 1. 철학과 포지셔닝

| | 코어홀딩 (기존) | **밸류코어 (신규)** |
|---|---|---|
| 성격 | 모멘텀 코어 — "이미 달리는 말에 올라탄다" | 가치·성장 코어 — "싸게 사서 기다린다" |
| 진입 근거 | 추세·수급·RS | 재무제표 (DART) + 밸류에이션 (KIS) |
| 보유 기간 | 3~6개월, stale 자동매도 | 무기한, stale 룰 없음 (소외 기간 용인) |
| 리밸런싱 | 격주 | **분기 1회** (재무 갱신 주기와 일치) |
| 청산 트리거 | 가격 (트레일링/MA200 이탈) | **펀더멘탈 훼손** (적자 전환 등) + 재해 방지선 |

전략 키: `value_growth_core`. 내부 2버킷(가치/성장) 각 50:50.

## 3. 데이터 계층 (Phase 1) — `FinancialsProvider` 신설

`src/signals/fundamentals/financials.py` — 기존 `AssetGrowthProvider` 패턴 미러링 (30일 디스크 캐시).

- **소스**: DART `fnlttSinglAcnt` (자산증가율에 이미 사용 중 — **별도 API 계약 불필요**).
  파싱 계정과목 확장: 매출액 · 영업이익 · 당기순이익 · 자산총계 · 부채총계 · 자본총계
  (연결 CFS 우선, 없으면 별도 OFS). 최근 3개년 + 최근 분기(reprt_code 11013/11012/11014).
- **파생 지표**: 매출 YoY, 영업이익 YoY, 순이익 흑자 연수, 부채비율, ROE(순이익/자본),
  영업이익률 및 전년比 개선폭
- **기존 재사용**: KIS `fetch_batch_valuations`(PER/PBR/EPS/BPS), `AssetGrowthProvider`(감점),
  `DartChecker`(공시 리스크)
- **배당수익률**: pykrx DIV (KRX 인증 장애 시 생략 — 가점 전용이라 fail-open 허용)

## 4. 스크리너 (Phase 2) — `value_growth_screener.py`

**유니버스**: 시총 3,000억+ · 주가 5천원+ · 거래대금 10억+ · 관리종목/감사의견 문제 제외

**공통 자격 필터 (fail-closed — 재무 데이터 미확보 시 후보 제외)**:
1. 최근 2년 연속 당기순이익 흑자
2. 부채비율 < 200% (금융업 제외 — v1은 금융/지주 유니버스에서 배제)
3. **value trap 방어 게이트**: 현재가 ≥ MA200×0.9 **AND** 60일 수익률 ≥ -15%
   (신고가 요구 없음 — 소외주 허용하되 "떨어지는 칼"만 회피)
4. **섹터 캡: 동일 업종 최대 1종목** (절대 저PBR 스크리닝은 은행/지주 쏠림이 고전적 함정)

**가치 버킷 (100점, 컷 70)** (2026-08-04 리뷰 P1-2 반영 — 배당 10점은 DIV 데이터 소스
미확보(pykrx KRX 인증 장애)로 밸류에이션/안정성에 재분배. 소스 확보 시 재도입):
| 항목 | 배점 | 기준 |
|---|---|---|
| 밸류에이션 | 45 | PBR 유니버스 내 분위 25 (하위 20%=만점) + PER 분위 20 |
| 퀄리티 | 45 | ROE ≥10% 15 · 영업이익률 10 · 이익 안정성(3년 흑자) 15 · 시총 5 |
| 수급·추세 | 10 | MA200 위 5 + 외인/기관 순매수 5 |
| 자산확장 감점 | 0~-5 | 기존 `AssetGrowthProvider` 재사용 |

**성장 버킷 (100점, 컷 70)**:
| 항목 | 배점 | 기준 |
|---|---|---|
| 성장성 | 50 | 매출 YoY ≥15% 20 · 영업이익 YoY ≥25% 20 · 영업이익률 개선 +1%p 10 |
| 가격 체크 | 20 | PEG < 1.0 = 20 / < 1.5 = 12 (성장 대비 과도한 가격 회피) |
| 퀄리티 | 20 | ROE ≥12% 10 · 부채비율 <100% 5 · 이익 안정성 5 |
| 추세 | 10 | MA200 위 + 60일 수익률 플러스 |
| 자산확장 감점 | 0~-5 | 유상증자 기반 외형 성장 배제 |

## 4.5 LLM 정성 검증 단계 (2026-08-04 추가) — "왜 싼가?"의 판별

퀀트 스크리닝은 "통계적으로 싼 주식"까지만 찾는다. 사이클 피크 함정(이익 정점 = 저PER),
일회성 이익 왜곡, 구조적 디스카운트 vs 일시적 소외의 구분은 정량 필터로 불가능하다.
기존 엔진 자산(LLM 계층 + 전문가 브리핑 + 뉴스 파이프라인 + DartChecker)을 재사용해
정성 패스를 추가한다.

```
퀀트 스크리닝 (버킷별 top ~5, 계 ~10) → LLM 정성 검증 → 최종 후보 (버킷별 상위)
```

- **모델**: gpt-5.4 (STRATEGY_ANALYSIS 라인, fallback Gemini Pro) — 거래 복기와 동일 경로
- **입력 컨텍스트**: 종목별 재무 요약(FinancialsProvider) + 최근 30일 뉴스 sentiment +
  DART 공시 요약 + 해당 섹터 전문가 최신 브리핑 (있으면)
- **판정 4항목** (각 0~25점, 종합 ≥60 통과):
  1. **사이클 위치** — 이익이 업황 정점 부근인가? (피크면 감점)
  2. **이익의 질** — 일회성 손익·자산 처분으로 부풀려진 ROE인가?
  3. **디스카운트 성격** — 구조적(지배구조·사양산업) vs 일시적 소외(악재 과잉반응)
  4. **재평가 촉매** — 주주환원 확대·업황 반전·실적 개선 등 가시적 촉매 존재 여부
- **fail-closed**: LLM 호출 실패 시 해당 분기 신규 매수 보류 (기존 보유는 유지)
- **호출량**: 분기 1회 × ~10종목 — 비용 무시 가능 수준. 판정 결과는 Wiki에 기록해
  다음 분기 리밸런스 컨텍스트로 재사용
- **구현 위치**: `src/signals/fundamentals/value_qualitative.py` (cross_validator의
  LLM 2차 검증 패턴 미러링)

## DO — 후보 전용 판독

`scripts/ops/run_capture_readout.py`의 새 manifest version은
`deterministic-pregate-readout-v1`이다. 기존 `deterministic-capture-readout-v1`은
종전 LLM 관측에 계속 사용한다. 새 형식은 `decisions` 키가 없으며 이를 넣으면 거부한다.
LLM 판단 파일이 없다는 이유로 후보 관측을 실패로 처리하거나, 빈 판단 파일을 만들지 않는다.

새 프로필은 `report_pregate_candidate_observation.py`만 실행한다. 이 보고서가
선정·게이트·프레임 검증과 첫 BOOK·900초 뒤 BOOK·각 시점 장 상태를 함께 보존한다.
기존 시도 잠금, 배타적 생성, 사본 보존, 소스 지문, 실행 시간·용량 제한을 재사용한다.
CLI의 분석 시각은 실제 시계이며 미래 시각을 인자로 넣어 미리 판독하지 않는다.

| 구분 | 고정할 내용 |
| --- | --- |
| 수집 프로필 | `20261020-pregate-v1` |
| study | `/home/ubuntu/.local/share/qwq-entry-observation/20261020-pregate-v1/study.json` |
| study SHA256 | `0e863c1dfe595f42b273a0714c8bda6079707154e6403f6255f4f8d4f762381b` |
| 원장 | `/home/ubuntu/.local/state/qwq-entry-observation/20261020-pregate-v1/engine.jsonl` |
| 판독 준비 디렉터리 | `/home/ubuntu/.local/share/qwq-capture-readout/20261020-pregate-v1/` |
| 새 결과 디렉터리 | `/home/ubuntu/.local/state/qwq-capture-readout/20261020-pregate-v1/` |
| 판독 **시작** 허용 창 | 10월20일09:55~10:30 KST, 양 끝 포함 |
| 파일 한도 | study4MiB, 원장256MiB, 각 하위 출력32MiB |

준비 디렉터리의 `source/`는 검증된 소스 사본, `manifest.json`은 입력과 소스 지문을
고정한다. 실제 준비 시점·reader 커밋·지문·사전검사 결과는 이 변경 PR의 영수증에
기록한다. 거래 봇 SHA와 오프라인 reader SHA는 목적이 다르며 같을 필요가 없다.

```bash
/home/ubuntu/projects/qwq-ai-trader/venv/bin/python -I -B \
  /home/ubuntu/.local/share/qwq-capture-readout/20261020-pregate-v1/source/scripts/ops/run_capture_readout.py \
  --manifest /home/ubuntu/.local/share/qwq-capture-readout/20261020-pregate-v1/manifest.json --check
```

`--check`는 미래 파일이 없어도 입력 경로·소스·존재하는 study를 검사한다.
실수집 완료나 내용 검증 성공을 뜻하지 않으며 출력과 시도를 만들지 않는다.
실제 판독은 허용 창 안에서 활성화 결과와 봉인을 확인한 뒤 위 명령의 `--check`를
빼고 한 번 실행한다. 실패·만료 뒤에는 원본과 시도를 보존하고 새 판독 계획을 정한다.
사전검사는 rc0/`preflight_ok`, 실제 판독 명령 완료는 rc0/`diagnostics_complete`와
유효 JSON을 각각 확인한다. 어느 결과든 시도 영수증과 입력/출력 지문을 보존한다.

## 결과 전에 고정한 비교 — regime_bypass_only_v1

이 절은10월19일에 작성하며10월20일 가격 결과를 읽기 전에 버전 관리한다.
**오프라인 원인 분리용 비교**이고 새 매수 전략이나 실행 정책이 아니다.

- 집단: 고정 study의 첫 반환 스캔 전체. 가격 관측은 원래 순서 상위5종목만,
  빈 스캔 대체·상승한 종목 추가·다른 날짜 혼합·후보 재정렬을 하지 않는다.
- 기준: 각 후보가 실제로 기록한 시장 방어 통과/차단을 그대로 쓴다.
  차단되었다는 사실만으로 계좌 현금 수익을0으로 계산하지 않는다.
- 대안: 시장 방어에서 차단된 후보에 한해 **그 단계만 우회했다고 표시**한다.
  현금·overnight 입력·점수·보유·전략·교차검증·LLM·주문 준비 등 뒤 단계는
  실제 기록대로 두고, 미도달/결측은 `not_reached`/`unknown`으로 남긴다.
  따라서 대안의 최종 매수 승인이나 체결을 추정하지 않는다.
- 가격 기준: 원래 첫 유효성 판정 대상 BOOK과 그 관측 시각+900초 이후 첫 BOOK,
  허용 지연5초다. 불량 첫 호가를 유리한 다음 호가로 바꾸지 않는다.
  양쪽 장 상태·연결 세대·배정/구독 근거를 같이 확인한다.
- 첫 결과표: 전체 후보 수, 상위5 배정 결과, 실제 첫 차단, 대안의 다음 미확정 단계,
  기준 ask·후속 bid·시각·표시 호가 잔량·장 상태·결측 사유를 기록한다.
  이 잔량은 주문/보유/체결 수량이 아니다.
  가격 차이는 후보 관측값이며 놓친 순이익/회피 손실 금액으로 이름 붙이지 않는다.
  두 호가와 각 장 상태가 비교 조건을 충족한 후보에 한해
  `(900초 후 bid / 기준 ask - 1) × 100`을 **비용 차감 전 호가 변화율**로 표시한다.
  이는 spread를 반영한 관측값이며 수수료·세금·체결 대기·시장 충격은 미반영이다.
- 비용: spread는 ask/bid에 이미 포함된다. 수수료·세금·slippage 가정은 고정 study에
  실제 존재하는 값과 의미를 별도 확인할 때만 가정으로 표시하며, 이 후보 보고서의
  비용 검증/계산 결과로 표시하지 않는다. 검증하지 않은 비용은 null이며 실제 체결·
  가격 대기·수량·계좌 귀속 없이 실현 손익으로 바꾸지 않는다.
- 판정: 표본 최대5종목/첫 스캔1회는 임계값 최적화나 전략 채택의 근거가 아니다.
  이 비교에 맞춰 시장 방어·선정·사이징·LLM 설정을 자동 변경하지 않는다.

`account_return=null`, `net_pnl=null`, `profitability_pass=false`,
`production_eligible=false`를 유지한다. 도구가 제공하지 않는 경제성 항목은 후속 표에서도
null로 명시한다. 후보 전용 프로필의 `decision_recording_finality=not_applicable`은
판단 기록을 읽지 않았다는 뜻이며, 운영 판단 파일의 완결성이 확인됐다는 뜻이 아니다.
